# 주자 위치 추정

이 위치는 GPS가 아닌 통과 기록에 기반한 추정이다. 공식 기록을 수정하지 않는다.

- 마지막 유효 통과 거리와 누적 시간을 기준으로 평균 페이스와 직전 구간 페이스를 계산한다. 출발 시각을 임의로 가정하지 않는다.
- 이후 구간을 이동하는 데 걸리는 시간을 경사와 시간별 날씨 조건으로 적산한다. 이미 관측된 페이스에 환경 감속을 중복 적용하지 않도록 직전 관측 구간의 환경을 기준으로 정규화한다.
- GPX의 고도는 약 100m 창으로 경사를 계산한다. Minetti(2002)의 달리기 에너지 비용 다항식을 사용하되 경사는 ±25%, 비용 비율은 0.72–2.7로 제한한다. 개인별 속도를 검증한 모델은 아니다.
- 날씨는 Open-Meteo의 코스 출발점 좌표에 대한 시간별 모델값이다. 기온·강수량·날씨 코드·풍속·풍향을 사용하며, 진행 방향과 바람이 불어오는 방향을 비교한다. 날씨 감속 계수는 보정되지 않은 실험적 휴리스틱이며 예측 정확도를 보장하지 않는다.
- 날씨 데이터가 없으면 날씨 보정을 생략한다. 출발점의 날씨가 코스 전 구간의 국지 날씨를 대표하지 못할 수 있다. 시간별 API 결과는 30분, 실패는 5분간 캐시한다.
- 마지막 통과 이후 30분을 넘으면 추정을 중단하고 확인된 지점으로 표시한다. 다음 통과 기록이나 완주 기록이 확인되기 전에는 추정으로 다음 지점/결승선을 넘기지 않는다.
- 과거 대회는 마지막 확인 지점에 고정하고, 출발 전에는 출발점에 표시한다. 완주는 실제 완주 통과 기록으로만 확정한다.
- 베를린 비교 보정은 적용하지 않는다. 공식 결과 페이지는 결과 목록의 이용을 개인 정보 열람 용도로 제한한다. 재사용 가능한 구간별 코호트 데이터 및 이용 조건이 확보되어야 유사 페이스 비교를 구현할 수 있다. 완주 시간만으로는 레이스 중 위치를 검증할 수 없다.

## 검증 범위

합성 통과 기록과 GPX를 이용한 단위·통합 검사이며, 실제 선수 GPS와의 오차나 개인별 기상 민감도는 검증하지 않았다. 기록 갱신 지연, 중도 이탈, 정지는 페이스만으로 확정할 수 없다.
